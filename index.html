Windows compatibility guide

Connect VK M3 and VK M3 Lite in Chrome or Edge on Windows 10 and 11

Why Windows browsers block direct WebHID

MI_02

Valkyrie MI_02 exposes 32-byte commands using constant HID report items. macOS and Linux keep MI_02 accessible natively, whereas Windows Chrome and Edge prune empty PreparsedData collections and also block WebUSB on HID class 0x03.

Platform behavior

Windows 10/11 Windows (Edge and Chrome): use Local Helper
macOS / Linux macOS and Linux: native WebHID works directly (Linux needs hidraw udev rules)

Option 1: Windows executable (valkyrie-helper.exe)

127.0.0.1:19480
  1. Download valkyrie-helper.exe from GitHub Releases (built automatically on GitHub Actions from companion/valkyrie_helper.cpp).
  2. Run valkyrie-helper.exe. It listens only on 127.0.0.1:19480 and leaves official drivers intact.
  3. Click Connect via Local Helper and allow Local Network Access if the browser prompts.
valkyrie-helper.exe

Option 2: Python script (standard library only)

Python 3
  1. Run py companion/valkyrie_helper.py from the repository root.
  2. Then click Connect via Local Helper without modifying any Windows USB driver.
py companion/valkyrie_helper.py

Helper safety boundaries

0xFFEF

The helper binds strictly to loopback 127.0.0.1, opens only MI_02 (0xFF01/0x0010 or 0x0001/0x0000), rejects the 0xFFEF DFU/OTA interface, and blocks opcodes 0x18–0x2A except 0x20.
